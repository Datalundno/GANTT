# Datalund website

Marketing site for [Datalund](https://datalund.no) — custom Power BI visualizations.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Hosted on **GitHub Pages** via `.github/workflows/deploy-pages.yml` (builds on push to `main`).

Domain + DNS: [DOMAIN.md](./DOMAIN.md).
