DataLund Gantt

Plan and track tasks on a clear timeline inside Microsoft Power BI — with progress fills, milestones, collapsible groups, resources, cross-filtering, and tooltips.

This product page is the Help / Learn more URL for AppSource. For support tickets use datalund.no/support (must be a different URL).

What you get

  • Task bars with optional progress track + fill
  • Zero-duration milestones
  • Collapsible groups and color-by-resource
  • Today line, weekend shading, week/date axis labels
  • Selection / cross-filter, host tooltips, context menu
  • Runs fully sandboxed — no external network calls

Field bindings

  • Task (required)
  • Start Date (required)
  • End Date and/or Duration
  • Optional: Progress, Group, Resource, Tooltips
