DataLund Gantt chart

A Gantt chart visual for Power BI. Tasks, progress, milestones, and groups on one timeline.

AppSource Help page. For questions, use Support.

Features

  • Task bars with progress fill
  • Milestones (zero duration)
  • Collapsible groups with Expand / Collapse
  • Density presets (Compact / Comfortable / Large / Custom) — Format → General
  • Optional time window from today (3 / 6 / 9 / 12 months) — Format → General
  • Resource colors, today line, and weekend shading
  • Cross-filter and tooltips
  • No network calls — runs in the Power BI sandbox

Fields

  • Task and Start Date (required)
  • End Date and/or Duration
  • Optional: Progress, Group, Resource, Tooltips
