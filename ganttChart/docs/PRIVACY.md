# Privacy Policy — Chartvik Gantt Chart

**Last updated:** 2026-08-06  
**Publisher:** Chartvik  
**Product:** Gantt Chart custom visual for Microsoft Power BI

## Summary

The Chartvik Gantt Chart visual runs entirely inside the Power BI sandbox. It does **not** collect, store, transmit, or sell personal data.

## Data processing

- The visual renders fields you bind in a Power BI report (task names, dates, progress, groups, resources, and optional tooltip fields).
- All processing happens locally in the Power BI host (Desktop or service). The visual does not call external HTTP/S or WebSocket endpoints.
- The visual does not use cookies, analytics SDKs, or third-party tracking.

## Permissions

The visual declares no network or storage privileges in `capabilities.json`.
